# Hi there! I'm Samudra Mukhar Goswami 👋

## About Me

I'm a **Backend & Applied ML Engineer** focused on building **scalable, production-grade systems** that integrate machine learning into real-world applications.

I work at the intersection of **distributed systems, data pipelines, and ML deployment**, with hands-on experience designing **microservices**, handling **high-throughput APIs**, and deploying **containerized infrastructure**.

> Build systems that are not just intelligent, but **reliable, observable, and production-ready**.

## 💻 Projects

### 🔹 **Stock Prediction Microservice** 📈

* Designed a **modular microservice architecture** using **Go + FastAPI**
* Built an **LSTM-based forecasting pipeline** with clear separation of inference and API layers
* Fully containerized with **Docker**, integrated with **Streamlit UI**
* Structured for **extensibility and production deployment**

---

### 🔹 **Advanced Movie Recommendation System** 🎬

* Built a **hybrid recommendation engine**:
  * NLP-based sentiment analysis (**BERT**)
  * Visual similarity using CNNs
* Backend powered by **FastAPI + PostgreSQL + Redis**
* Focused on **low-latency retrieval and scalable architecture**
* Designed as a **plug-and-play ML system**, not just a prototype

---

### 🔹 **SimpleBank API** 💳

* Developing a **production-grade banking backend** using:
  * **Go, PostgreSQL, Redis, gRPC**
  * **PASETO-based authentication**
* Emphasis on:
  * **Security-first design**
  * **Role-based access control**
  * **Clean architecture & service isolation**
* Targeting **cloud-native deployment on AWS**
